# 🏥 Polyclinic No. 5 — Appointment Booking System

### ICT University Project | Astana IT University

## 📌 Project Overview

This project presents a proposed digital appointment booking system for Polyclinic No. 5 in Astana, Kazakhstan.

The goal is to make medical appointment scheduling easier, faster, and more accessible for patients.

## ❗ Problem Statement

Patients may experience several difficulties when booking appointments:

- Long queues at reception
- Busy telephone lines
- Risk of double bookings
- Difficulties accessing appointment information

## 💡 Proposed Solution

Our team designed a concept for an online appointment booking system that would allow patients to:

- View available appointment slots
- Select a convenient date and time
- Book appointments online
- Choose another time if a selected slot is unavailable

## 🛠️ Proposed Technologies

- **Frontend:** Patient-friendly interface
- **Backend:** Server-side appointment processing
- **Database:** PostgreSQL
- **Data Exchange:** JSON over HTTPS
- **Security:** Access control and data backups

## 👩‍💻 My Contribution

**Role: Testing & Analysis**

My responsibilities included:

- Analyzing potential system problems
- Identifying possible booking errors
- Considering user accessibility
- Evaluating appointment booking scenarios

One important scenario involved a patient selecting an unavailable appointment slot. The proposed system allows the patient to return to the available slots and choose another time.

## ♿ Accessibility

The system design considers patients who may have difficulties using digital services, including elderly users.

Our proposed interface emphasizes clear text, simple navigation, and an understandable booking process.
